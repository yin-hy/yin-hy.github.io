# yin-hy.github.io

Static GitHub Pages personal website for Haoyu Yin.

The site uses static HTML, CSS, and JavaScript, so deployment only requires pushing these files to the repository's GitHub Pages branch.

The full-page background, `art/daylight.webp`, was created with the built-in image generation tool and encoded as WebP for the website.

> Use case: photorealistic-natural. Asset type: seamless-looking full-viewport background photograph behind text on a refined academic personal website. Wide landscape composition, approximately 16:9. A close, straight-on architectural photograph of a single unbroken, pale neutral silver-gray matte plaster wall, with softly diffused natural daylight passing through an unseen frosted window. Broad, very low-contrast areas of daylight and shadow, with one softly edged expanse of light crossing the surface at a diagonal; shadow is continuous to the image edges rather than a floating shape. Light should feel physical and photographic, like an understated fine-art print. Fine paper-like surface detail, almost invisible at website scale. Keep all regions light, including the corners; center and left comfortably readable underneath dark text. Slight silvery blue undertone in shadows, otherwise neutral gray. Avoid visible window frames, objects, people, scenery, hard edges, line art, bands, mesh, repeating patterns, bokeh, circular spots, blobs, heavy grain, strong contrast, text, logos, and borders.
